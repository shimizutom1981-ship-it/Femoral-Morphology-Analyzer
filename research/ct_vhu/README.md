## 1. 推奨する CT-vHU の定義（v0.1）

記号：HU(y) は元CTの値、R_r(x) は x を中心とする半径 r mm の球に**中心が入る**ネイティブボクセルの集合
（0.72×0.72×1.0 mm では r=0.5 mm は1ボクセル＝単一HUと同じ）。

| 層 | 式 | 既定値 | 役割 |
|---|---|---|---|
| 局所平均（CT-vHU本体） | vHU_r(x) = (1/\|R_r(x)\|) Σ_{y∈R_r(x)} HU(y) | r = 1.5, 2, 3 mm を保存 | 局所骨量の連続値。色表示・骨質評価の基盤 |
| 適応半径 | r(x) = argmin_{r∈{1,1.5,2,3}} \|r − t₀(x)\| | t₀＝予備マスク（450 HU＋連続性）の局所厚 | 薄い皮質は小さく、厚い皮質は大きく |
| 存在層 | P(x) = [ vHU_{r(x)}(x) ≥ 300 HU ] ⊕ 球1 mm | 300 HU | 立体的に骨が存在するか |
| 局所半値閾値 | T(x) = clip( ( max_{B₁.₅(x)} HUs + min_{B₁.₅(x)} HUs ) / 2, 400, 800 ) | 窓半径1.5 mm, 下限400, 上限800 | 部分体積を考慮した境界位置 |
| 境界場 | B(x) = HUs(x) − T(x)（P外は min(B, −1)） | HUs = Gauss σ0.35 mm | **連続値**。B=0 が境界、正が骨 |
| 3D連続性 | V(x) = x を含む {B≥0} の26連結成分体積 | V_min = 20 mm³ | 孤立高HU点と連続した骨を区別 |
| 骨 | {B ≥ 0} ∩ {V ≥ V_min} ∖ 金属(≥2500 HU ⊕ 0.75 mm) | | |
| 皮質殻／殻内 | 骨膜側エンベロープ内で髄腔（開放0.75 mm・閉鎖2 mm）に属さない骨＝殻、属する骨＝殻内高密度 | | CFR分母（殻内縁）と calcar 等を分離 |
| 皮質厚 | 殻ボクセルから骨膜面法線方向に B を補間し、B≥0 区間の両ゼロ交差間距離 | ±7 mm, 0.05 mm刻み | 亜ボクセル厚（CBM の法線プロファイルの考え方） |

保存する補助マップ：局所SD（r=2）、450 HU以上の占有率（r=2）、勾配強度 |∇(G_{0.5}∗HU)|、
連続性 log10(成分体積)、局所閾値 T、ラベル（1殻 2殻内高密度 3孤立高HU 4金属除外）。

### 推奨する局所領域の形状とサイズ
- **境界の位置決めには大きな平均領域を使わない**。平均HU＋固定閾値は半径とともに内縁が髄腔側へずれ、薄い皮質を失う（下表）。
- 境界は「元HUの局所半値」で決め、局所平均（vHU）は**存在判定と骨質の連続値表示**に使う。
- 存在判定の半径は**局所厚に応じて 1〜3 mm を選ぶ適応型**。固定3 mm（午後のv1案）は薄い皮質と、皮質から離れた薄い calcar 板を消す。
- 単一の固定半径で平均する場合は、球より**骨軸方向の楕円体・皮質面に沿う楕円体**が境界を保つ（v1と同じ傾向）。

相関ノイズSD 30–45 HU。皮質厚0.4–6.5 mm、移行帯0.5–1.5 mm、calcar 間隙0–3 mm、孤立点：高密度微小球（半径0.3–0.9 mm）40個＋単一ボクセルスパイク40個。

- 薄皮質保持の内訳（推奨）：正常型0.99、皮質内不均一0.96、骨硬化0.70、金属0.71、**骨粗鬆症型0.15**（0.4–0.9 mm・1050 HU の皮質は PSF と格子で 400 HU 未満になり、どの手法も検出できない＝分解能限界。固定450 HUも0.16）。下限を350 HUへ下げると保持0.70だが孤立点誤検出0.06。
- **上限800 HU の必要性を再確認**：上限なし・1200 HUでは厚い皮質の内側が割れる（厚皮質の割れ 26%・7%）。700–900 HU では差が小さい。
- calcar 分離率（間隙別、推奨）：0 mm 0.00、0.5 mm 0.81、1 mm 0.97、2 mm 0.97、3 mm 0.94。固定3 mm 存在判定は 3 mm で 0.00（離れた薄板を消す）。間隙0 mm（融合）は画像だけでは分離不能。
- 金属4体：推奨法の金属近傍の内縁MAE 0.14 mm（固定450 HU 0.18）。ストリークは単純化したモデルで、実CTの金属アーチファクトの再現ではない。
- 皮質厚マップ（法線プロファイル）：真値比較 MAE 1–2 mm帯 0.17、2–4 mm帯 0.12、4–8 mm帯 0.40 mm。1 mm未満は検出された所で MAE 0.28 mm。
- 計算時間（ファントム61×61×24）：推奨 0.27 s、固定閾値 <0.01 s。実CTの大腿骨ROIでの時間は未計測。
- 骨硬化（内膜に接する高密度海綿骨）は全手法で約4–5割が骨と判定。推奨法では殻に接して融合するため「殻」側に入り、厚さを増やす。**骨硬化と皮質を形だけで分けることは未解決。**

## 3. 実CTでの実行（PC）

```
pip install SimpleITK numpy scipy scikit-image pandas matplotlib
cd research\ct_vhu
python run_ctvhu.py --ct "<匿名化CT .nrrd/.nii.gz/DICOMフォルダ>" ^
    --roi "<上村AIの大腿骨マスク.nrrd>" --use-roi-as-outer ^
    --out "D:\磐田CDデータ\<研究ID>\ct_vhu_v0.1" ^
    --compare uemura="<上村マスク>" gpt_cad="<HU450_all.nrrd>" fixed450="<既存マスク>"
```

- 元CT・DICOMには書き込まない（同一パスへの保存は拒否）。出力は NRRD＋同名JSON（コード版・パラメータ・入力・日時）。
- `--roi` 指定時は大腿骨の外接箱＋8 mm だけ処理。`--roi-label` で左右別ラベルにも対応。
- 出力：`ctvhu_vhu_mean_r1.5/r2/r3`、`vhu_presence`、`vhu_sd_r2`、`vhu_occ450_r2`、`grad_mag`、`continuity_log10mm3`、
  `t_local`、`boundary_field`、`cortical_thickness_mm`、`labels`、`ctvhu_outer_LPS.stl`、`ctvhu_shell_LPS.stl`、
  `ctvhu_review_points.mrk.json`（手法間で骨判定が割れる部位上位20）、`ctvhu_summary.json`（既存モデルとの**一致度**。真値に対する精度ではない）。

## 4. 3D Slicer での表示

```
python slicer\make_colors.py          # 初回のみ：カラーテーブルと共通表示範囲
```
Slicer の Python コンソール：
```
CT_PATH = r"<元CT>"; OUT_DIR = r"<出力フォルダ>"
exec(open(r"<repo>\research\ct_vhu\slicer\load_ctvhu.py", encoding="utf-8").read())
show("vhu_mean_r2"); show("grad_mag"); show("continuity_log10mm3"); show("cortical_thickness_mm"); show("labels")
set_range("vhu_mean_r2", 0, 1400); set_opacity(0.6); jump(1)
compare_cad(r"...\HU450_all_LPS_mm.stl", "GPT_CAD")
```
色は値を持つスカラー画像の表示で、データプローブに各位置の数値が出る。表示範囲は `slicer/display_ranges.json`
（全症例共通）。`OUT_DIR` に同名ファイルを置けば症例別に上書きできる。

## 5. ファイル
- `ct_vhu/features.py` 局所統計（球・楕円体・表面方向楕円体、平均・中央値・Gauss・SD・パーセンタイル・占有率）、勾配、3D連続性、局所厚

- `phantom/` ファントムv2・評価・集約・厚さ検証
